# Scope MVP — VORA

À remplir en équipe dès que possible (idéalement dans la 1ère heure du hackathon).
Basez-vous sur le cahier des charges complet, mais ne gardez QUE ce qui est réalisable
et démontrable en 48h.

## ✅ Inclus dans le MVP (priorité critique)

- [ ] Authentification passager (téléphone ou email)
- [ ] Authentification chauffeur (simplifiée — pas de vraie validation documentaire)
- [ ] Carte + position actuelle
- [ ] Choix destination (recherche simple ou point sur carte)
- [ ] Estimation prix + durée avant commande
- [ ] Demande de course → matching (même simplifié : chauffeur disponible le plus proche)
- [ ] Suivi de la course (statuts : demandé → accepté → en cours → terminé)
- [ ] Paiement simulé
- [ ] Évaluation post-course
- [ ] Historique simple

## 🟡 Inclus si le temps le permet (priorité élevée)

- [ ] Annulation avec règles de frais
- [ ] Back-office admin minimal (liste utilisateurs, courses)
- [ ] Notifications push

- [ ] *(ex. assistant intelligent, prédiction de zones, mode dégradé réseau, accessibilité PMR...)*
